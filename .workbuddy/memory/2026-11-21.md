# 2026-11-21 Marknest 功能三梯队（14 项，用户要求「完成这三个梯队任务」）

## 数据模型与基础设施
- `types.ts` 扩展：Bookmark 加 `deletedAt`（回收站软删）/`archived`（分层存储）/`browserId`（浏览器同步源）；新增 BrowserSyncState/SmartFolder/AutoTagRule/HealthMonitor/ArchiveConfig/ShortcutBindings/SearchHistoryItem；Settings 加 8 个新字段；Group 加 `private`。
- 新 `src/lib/features.ts`（纯函数）：URL 追踪参数清理 `stripTrackingParams`（白名单 utm_*/fbclid/gclid 等，保留其它 query/hash，没命中原样返回避免重编码）、`urlFingerprint`、高级搜索 DSL `parseSearchQuery`/`matchesQuery`/`hasAdvancedSyntax`、智能文件夹匹配、自动打标签 `autoTagsFor`、数据洞察 `computeInsights`、PIN 哈希、快捷键 `SHORTCUT_ACTIONS`/`keyComboFromEvent`/`matchesCombo`、私密分组判定。
- `storage.ts`：`DEFAULT_SETTINGS` 补全新字段并加 `normalizeSettings` 深合并迁移（老用户缺字段自动补）；分层存储 `loadArchivedBookmarks`/`saveArchivedBookmarks`（chrome.storage.local 的 `mn:archive`），`buildV3Payload` 过滤归档书签（不占 sync 配额），`loadState` 三格式分支均并入归档书签，`saveState` 阶段 4 写 local。
- `manifest.json` 加 `alarms` 权限。

## 第一梯队
- **回收站**：deleteBookmark(s) 改软删（设 deletedAt），新增 restoreBookmarks/purgeBookmarks/emptyTrash；App 里 `bookmarks` = allBookmarks 过滤软删，回收站视图单独读 allBookmarks；RecycleBinDialog + 列表内回收站视图。
- **浏览器增量同步**：新 `src/lib/browserSync.ts`（队列 `mn:browser-events` 存 local，service worker 写、前端 `mergeBrowserEvents` 按 browserId 合并 created/changed/moved/removed，文件夹→分组用 settings.browserSync.folderMap）；background.js 监听 chrome.bookmarks 四事件入队（同节点去旧、限长 500）；store 监听 local onChanged 消费；全量导入也写 browserId + folderMap 以便后续增量识别。
- **UTM 清理**：addBookmark(s)/浏览器导入/增量同步均按 settings.stripTracking 应用；URL 指纹统一去重逻辑。

## 第二梯队
- **智能文件夹 + 自动标签**：SmartFoldersDialog（保存查询为虚拟分组，侧栏独立区块 + 命中数）；SettingsDialog「自动标签」配置域名/关键词→标签规则，收藏时自动追加。
- **高级搜索 + 历史 + 批量编辑**：搜索框支持 tag:/domain:/group:/before:/after:/unread/pinned/untagged，Enter 记住搜索词（searchHistory），下方显示最近搜索可点；BatchEditDialog 批量改备注/替换网址前缀/按规则重命名标题（store 加 bulkSetDescription/bulkReplaceUrl/bulkRename）。
- **死链巡检 + 快捷键自定义**：后台 alarm（mn-health-check，间隔可配）到点写 `mn:health-due`，前端提示检测；顶栏死链角标（healthMonitor.deadIds）；SHORTCUT_ACTIONS 8 个动作可重绑，键盘 handler 用 matchesCombo 读自定义绑定，ShortcutsDialog 显示当前绑定 + 跳设置入口。

## 第三梯队
- **分层存储**：Settings「分层存储」配置 idleDays，archiveColdBookmarks/unarchiveAll；归档集合的 local 落盘由 store 内 `archivedKey` useEffect 驱动（避免 flushArchive 读到未刷新的 stateRef 造成回写竞态）；卡片显示「归档」标记。
- **数据洞察**：InsightsDialog（总数/已分组/已打标签/总访问 + 域名/标签分布 + 12 月趋势 + Top10）。
- **私密分组**：设 PIN（hashPin 存 settings.pinHash），GroupSettingsDialog 加私密开关（需先设 PIN）+ 分享页按钮；未解锁私密分组（含子树）书签全视图隐藏，点击弹 PinDialog，单一 PIN 解锁本会话全部。
- **分享页**：exportGroupHtml 生成独立自适应深浅色 HTML，downloadFile 导出。
- **AI 辅助整理**：未自建外部 LLM 调用（扩展无后端/OAuth，且会引入权限与隐私成本）；以「自动打标签规则 + 智能文件夹 + 数据洞察」本地能力覆盖其整理目标，属有意取舍。
