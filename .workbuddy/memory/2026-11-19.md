# 2026-11-19

## Marknest UX 改进 P0-P2 全部完成（bookmark-hub）

基于对 v1.4.1 代码的审阅，完成 10 项用户体验改进，typecheck + build 均通过。

### P0
- **撤销栈一致性**：新增 `redoStack`；`performUndo` 弹栈时把当前状态压入 redo。所有 toast「撤销」回调由各自的 `store.importData(snapshot)` 改为统一传 `performUndo`，修复「点撤销后 ⌘Z 回退到同一快照」的重复撤销 bug。修正 toast onClick 顺序（先清 toast 再执行 action），否则「已撤销」提示会被抹掉。
- **模态焦点陷阱**：新增 `src/lib/useModalFocus.ts`（模块级 modalStack，仅栈顶响应 Tab；打开聚焦弹窗内、关闭焦点归位；支持叠加弹窗）。接入全部 8 个 aria-modal 弹窗（BookmarkDialog / GroupCreateDialog / GroupDialog / TagDialog / DataDialog / ShortcutsDialog / QuickSwitcher / GroupSettingsDialog），dialog 节点加 ref + tabIndex=-1。

### P1
- **重做**：`⌘/Ctrl+Shift+Z` 与 `⌘/Ctrl+Y` 触发 `performRedo`；新改动清空 redo 栈。ShortcutsDialog 与 README 已更新。
- **搜索/切换器反馈**：主搜索用 `useDeferredValue(query)` 做防抖，高亮同步用延迟值；QuickSwitcher 统计 `totalMatches`，被截断时提示「还有 N 条结果」。
- **URL 实时校验**：BookmarkDialog 加 `urlTouched`，失焦/提交后即时显示内联错误，输入合法即消除；加 aria-invalid/describedby。
- **删除分组前置确认**：新增 `ConfirmDeleteGroupDialog.tsx`（alertdialog + 焦点陷阱）。App 层 `requestDeleteGroup`/`confirmDeleteGroup`/`pendingDeleteImpact` 统一两个删除入口，确认前显示「N 个子分组、M 个书签将上移」。
- **最近访问语义**：副标题改为「仅统计在 Marknest 内打开 · N 个」。

### P2
- **触屏操作栏**：`@media (hover:none)` 下操作栏 opacity 1 + 常驻背景，卡片加底部内边距防遮挡。
- **favicon 闪烁**：BookmarkRow 的 Favicon 改为「首字母垫底 + img 加载成功后淡入」（`.bm-favicon-wrap` / `.bm-favicon--remote.is-loaded`）。
- **角标封顶**：utils 新增 `formatCount`（0 不显示，>99 显示 99+），替换侧栏 5 处数字角标。
