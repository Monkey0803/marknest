# 2026-11-18

## Marknest v1.1.0 迭代完成（bookmark-hub）

用户确认按 A+B 组合方向推进版本迭代，全部完成并已发布：

- **搜索命中高亮**：`utils.ts` 新增 `highlightSegments`；BookmarkRow 加 `Hl` 组件 + `.bm__hl` 荧光笔样式（深浅主题适配）。
- **多级撤销**：App 内 `undoStack`（20 步快照），`pushUndo` 在改动前压栈并返回快照供 6 秒 toast 撤销复用；`⌘Z` 触发 `performUndo` → `importData` 还原。覆盖删除/批量/移动/分组删除/标签改名。
- **Quick Switcher**：新组件 `QuickSwitcher.tsx`，`⌘K` 唤出，搜命令/分组/书签（书签限 10 条，总 14 行）；`/` 改为聚焦搜索框。
- **阅读清单**：Bookmark 增加 `readLater/readAt`（可选字段，向后兼容）；`visitBookmark` 打开时自动清除；侧栏入口带未读角标；卡片操作栏新增切换按钮。
- **健康检查**：新 `lib/health.ts`（no-cors fetch + 8s 超时 + 并发 6），DataDialog 新增 section，可单删/一键删死链（带撤销）。
- **分组模板**：DataDialog 内置 4 套模板（内容创作/学习计划/项目工作/日常生活），App `onApplyTemplate` 跳过同名分组。
- **备份提醒**：`localStorage mn:lastExportAt`，超 30 天或从未导出时在备份 section 显示提醒。
- **CI**：`.github/workflows/ci.yml`（typecheck + build + 上传 dist artifact）。
- **拆分**：`EmptyState.tsx`、`ShortcutsDialog.tsx` 独立成组件（App.tsx 1755 → 1658 行）。

发布：commit `c9c7916`、tag `v1.1.0` 已推送 origin；GitHub Release 已带 `marknest-v1.1.0.zip`：https://github.com/Monkey0803/marknest/releases/tag/v1.1.0
